## Deployment Instructions

### Extract
```bash
unzip TitanZero-Unified.zip
```

### Install to MagicAI
```bash
cp -r TitanZero-Unified/primary/* your-magicai/app/Extensions/
cp -r TitanZero-Unified/shared/* your-magicai/app/Extensions/
```

### Dependencies
```bash
composer require \
  twilio/sdk \
  vonage/vonage-php-sdk \
  telnyx/telnyx-php \
  elevenlabs/elevenlabs \
  google/apiclient \
  microsoft/graph
```

### Configure
```bash
# Copy .env variables and fill in your API keys
php artisan migrate
php artisan config:cache
php artisan route:cache
```

### Setup
```
Visit: http://your-app/dashboard/wizard/chatbot-setup
```

## Key Architecture Principles

1. **Single User Persona** — Users only speak to Titan Zero
2. **Clean Tier Separation** — Each tier has single responsibility
3. **Scalable to 405+ Components** — Can expand without changing architecture
4. **Bidirectional Communication** — Tiers call down, report up
5. **Audit Trail** — Every agent call is logged and traceable
6. **No Duplicate Code** — Shared services across all extensions
7. **Extensible Registries** — Can add components without breaking existing

## Testing the Platform

### Test 1: Basic Conversation
```
User: "The heater has stopped working"
↓
Titan Zero identifies tenant, property, maintenance issue
↓
Routes to Tenant Manager
↓
Calls Property Management, Maintenance, Safety Assistants
↓
Invokes: Create Work Order, Send Access Request, Send SMS agents
↓
System creates work order, notifies tenant, schedules technician
```

### Test 2: Booking to Invoice
```
User: "Schedule a pool cleaning for next Tuesday"
↓
Titan Zero identifies customer
↓
Routes to Customer Manager
↓
Calls Scheduling Assistant
↓
Invokes: Find Available Appointment, Create Appointment agents
↓
Upon completion: Create Invoice, Send Invoice agents
```

### Test 3: Compliance Audit
```
Owner: "Are we ready for audit?"
↓
Titan Zero identifies owner
↓
Routes to Owner Manager
↓
Calls Compliance, Quality, Audit Assistants
↓
Invokes: Verify Credential, Check Expiry, Generate Audit Pack agents
↓
Returns audit readiness report with action items
```
